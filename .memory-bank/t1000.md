# T-1000 — liquid-metal infiltrator (core 1.71.0, branch feat/t1000-infiltrator)

Design: `docs/design/2026-11-06-t1000-design.md`. Sources / cue sheet: `tools/assets/t1000_sources.md`.

## Shape
- Server `t1000/`: `T1000Entity` (extends `CitizenEntity`; synced form / arms / action / wounds / disguise kind,
  two-pool damage, combat contacts, sounds), `T1000Brain` + `T1000Hunt` (one goal at priority 0 over the citizen goals),
  `T1000Spawner` (rare roll + dormant wake), `T1000SavedData` (`data/viltrumitecore_t1000.dat`), `T1000Commands`,
  `T1000Disguises` (kind + payload, `citizen` built in), pure `T1000Rules` / `T1000SpawnRules` / `T1000Damage` /
  `T1000WoundMath` (JUnit), `T1000Sounds` (16 events).
- Client `client/t1000/`: `T1000Renderer` (citizen renderer + metal layer), `T1000Model` (pose hook `citizenPoses`),
  `T1000Poser` (stances replace citizen gestures once revealed), `T1000Body` (own CPU mesh, matcap), `T1000Shapes`
  (arm rings: blade / hook / spike; head split; `slump` melt column), `T1000Droplets`, `T1000Matcap`, `T1000Qa`
  (playtest `t1000state` / `t1000look`).
- Commands (op 2): `/t1000 status | spawn [pos] | remove | natural on|off|check|force |
  config chance|delay|interval|max <v> | debug reveal|conceal|puddle|blade|hook|split|hunt|destroy`.
- Config: `t1000NaturalCheckSeconds` 300, `t1000NaturalChancePercent` 1.5, `t1000RespawnDelayMinutes` 120,
  `t1000MaxActive` 1. `natural force` skips the off switch, the respawn delay, the startup grace and the roll but keeps city / peaceful /
  limit (no duplicates past `max`); `spawn` is the operator path (no gates).

## Invariants
- The entity type is never saved in chunks; the world data keeps the record. Unload / stop / far from players /
  lost off the walk grid → dormant (`sleep`), wakes after `WAKE_DELAY_TICKS` 2400 and `STARTUP_GRACE_TICKS` 3600
  near a player in the city, out of view. Only `KILLED` / `DISCARDED` by others / `die` count as destroyed (+ delay).
- Citizen seams it overrides: `citizenMind()`, `discardWhenStuck()` false, `cityTracked()` false (never in
  `CityManager.citizens()`, so trims / despawn never see it), `capturable()` false, `lostOffGrid()` (citizens are
  discarded there; the T-1000 vanishes to dormant when unobserved). Any new citizen cleanup path must go through a
  seam, a plain `discard()` on a T-1000 counts as its destruction (found in playtest: ReturnToGrid did that).
- In disguise it is a citizen: vanilla player hurt / step sounds, no metal sound, no glow, name "Citizen".
  Metal sounds only when `form().revealed()`; the entity's `SoundSource` switches to HOSTILE.
- Hit sounds by kind (`reactToHit`): normal → impact; COLD → crack only when frozen; HEAT → flow. Never a sound per
  fire / freeze tick of another kind.
- Sounds: `sounds/t1000/<event>_<n>.ogg.b64` in `binassets`, events in `sound-overlays/t1000.json`, all from
  `tools/sfx/t1000.py` (CC0 Freesound via Openverse; never hand-edit the OGGs). `T1000AssetsTest` checks events,
  files, lang keys in all 12 locales and that every recording is credited.
- Lang: only the overlay `lang-overlays/t1000/<locale>.json` (12 files together). `processResources` copies the
  `commands.viltrumitecore.t1000.*` keys into `data/viltrumitecore/lang/en_us.json` for dedicated servers / RCON.

## Testing
- Unit: `./gradlew :viltrumitecore:test --tests '*t1000*'` (rules, damage, saved data, assets, client mesh / poses;
  preview sheet `viltrumitecore/build/t1000-preview/t1000_sheet.png`).
- Game: synthetic city `python3 tools/city/smoke_flat_city.py <world>` (flat, feet y -60), then `/forceload add -96 -96
  96 96`, `/city enable`, `/city populate 60`, `/difficulty normal`, `/t1000 natural force`. City enable does not survive
  a reload of that synthetic world (enable again). Survival + resistance to be hunted; staring at the stalker
  provokes the reveal. `/effect give @e[type=viltrumitecore:t1000] glowing` to find it (it is named "Citizen").
- Weaknesses verified in game: powder snow freeze → heavy hit shatters; fire heats; lava destroys in ~7 s.
