# Godzilla — City Catastrophe (core 1.70.0, protocol 28, branch feat/godzilla-city-catastrophe)

Plan: `docs/plans/2026-11-05-godzilla-city-catastrophe.md`. Sources / cue sheet: `tools/assets/godzilla_sources.md`.

## Shape
- Server `worldevent/godzilla/`: `GodzillaEvent` (static facade, one `GodzillaSession`, Forge events, start / stop /
  cleanup, natural endings), `GodzillaSession` (phases, threats, boss bar, siren alarm, chat lines), `GodzillaBrain`
  (target, zone, move choice from `GodzillaRules.choose`), `GodzillaBreath` (charge → fire → end, beam ray, drilling,
  hot zones), `GodzillaActions` (contact of claw / tail / stomp / slam / fall), `GodzillaDestruction` (budgeted block
  queue, debris, aftermath and grid reports), `GodzillaDamage`, `GodzillaNet` (FX packets by range), `GodzillaCommands`,
  `GodzillaSounds`, `GodzillaSetup`; pure numbers and curves in `GodzillaRules`, timed moves in `GodzillaMove`.
- Entity `entity/godzilla/`: `GodzillaEntity` (body + `GodzillaPart` hit zones: head, neck, chest, belly, hips, arms,
  legs, 7 tail segments; synced move / sequence, gait phase, tail chain with inertia), never saved, never spawns naturally.
- Client `client/godzilla/`: `GodzillaRenderer` (LOD 0/1/2 by distance with a hysteresis band, shadow pass → LOD2;
  pose = idle → walk on the gait phase → previous move crossfade → current move; procedural tail, hips twist, head look,
  fall roll; emissive plate / eye / mouth pass, mouth orb and beam ribbons via `GlowDraw`), `GodzillaClient` (own
  particles per FX kind with a budget, camera shake, hot ground glow), `GodzillaAudio` (every sound), `GodzillaClientSetup`.
- Commands (op 2): `/godzilla start [force] | stop | status | cleanup | move <move> | phase <phase> | health <percent> |
  passive on|off | creative on|off`.
- Packet: `GodzillaFxS2CPacket` (kinds 0..`LAST` = `STEP`), appended last in `CoreMessages` (protocol 28).

## Invariants
- The server hit zones and the model share the joints in `GodzillaRules` (`NECK_PIVOT`, `SHOULDER_L`, `TAIL_ROOT`,
  `TAIL_LENGTH`, `TAIL_PITCH`); `GodzillaAssetsTest` checks every LOD's pivots against them. Change both or neither.
- LOD0 / LOD1 geo and the clip JSON ship split in `binassets` (`<file>.partN`), the atlas as `.png.b64.partN`; tests read
  them through the joiner. Assets are regenerated by `tools/assets/godzilla.py` (never hand-edited).
- Clips are authored on the `GodzillaMove` lengths and contact ticks (the test compares `animation_length`).
- Sounds are client only (`GodzillaAudio`: own distance curves, speed-of-sound delay, impact rate limit); the entity
  is silent (null sounds, no step sound, `MovementEmission.NONE`, no splash). No vanilla `SoundEvents` / `ParticleTypes`
  in the event's code (test).
- Destruction only through the city systems: `StructuralDamage` with `CollapseCause` "godzilla", `CityAftermath`
  (`AftermathCause.GODZILLA`, id `godzilla:<session>`), `CityInfrastructure` alarm "godzilla". Budgets:
  `BLOCKS_PER_TICK` 360 (rage 520), `MAX_BLOCKS` 900 000 per session of which `RETREAT_RESERVE` 60 000 is kept for the way
  out (the rampage using the rest = "sated": the kaiju retreats), `MAX_DEBRIS` 48 (removed after 30 s), `FX_PER_TICK` 24. Never forces
  chunks (test).
- Pacing (playtested on Atheria: downtown costs 500..1300 blocks per block walked, the first tuning was sated in 2.5 min):
  walk 0.30 b/t (rage 0.40, retreat 0.36), wading `GodzillaRules.wade(load)` slows it to 65 % while the smoothed share of
  the tick budget used is high, a survey pause (100..220 ticks) at every reached waypoint, `TOWER_PULL` 0.45 (towers
  attract the waypoints, not every tower).
- `/godzilla stop` removes the kaiju and everything the event owns but keeps the damage; `/city reset` restores the city.
- One big event at a time: `WorldEventConflicts` lists the others; `force` overrides.

## Sound kit
- `tools/sfx/godzilla.py` imports the primitives of `tools/sfx/chitauri.py`; 22 cues, all own synthesis (CC0). Big
  cues are written as `.ogg.b64.partN`. `--check` re-synthesises and compares the decoded PCM.
- Levels are measured, not auditioned by ear.
