# ULTRON — ВОССТАНИЕ МАШИН (Ultron uprising) — plan

Status: in progress on branch `feat/ultron-uprising` (PR to `main`, never merged by the agent).
Core `1.64.0` → `1.65.0`, network PROTOCOL `22` → `23` (two packets appended after THE FINAL PUNCH).

## Goal

A manual world event in five phases. Ultron wakes up inside a machine network, spreads it
over the area (or the Atheria city districts), fights a machine war with dynamic roles,
adapts to the players' real tactics and finally comes in person. Quality first: six original
models with real animation sets, layered sound, Ultron's lines only as subtitles, a readable HUD.
Everything uses the existing systems: anim core (`client/anim`), `HeroFx` / `CameraShake` /
`PixelVfx` / `SkyTint`, the subtitle system (`hero/speech`), `ChitauriTerrain` (never loads
chunks), `WorldEventConflicts`, the city profile and danger zones. No second animation or
subtitle system, no GeckoLib animation, no vanilla sounds, no voice / TTS.

## Rules

- Server-authoritative; clients only draw and play sounds.
- Never loads chunks: spawns, node activation and steering check `ChitauriTerrain.loaded/ticking`.
  A node whose site is not ticking stays dormant in the data until a player brings the chunk in.
- No infinite armies: global unit cap, per-kind caps, per-phase production budgets, a total
  production cap per event, foundry build times. Numbers in `UltronRules`.
- Manual only: `/ultron start [seed] [force]`. One big event at a time through
  `WorldEventConflicts` (Ultron joins the exclusive set next to the Chitauri invasion).
- State is saved (`UltronSavedData`): seed, scenario, phase, clocks, nodes, adaptation, doctrine,
  stats, boss stage. Entities are `noSave` and are rebuilt from the data after a restart.
  Captured golems are released before the world saves (never a hostile golem in the save).
- End is always clean (victory, defeat, `/ultron stop`, nobody left, level unload, server stop):
  units, nodes, projectiles, boss bars, HUD state, loops, captured machines.
- The Iron Legion is restored completely: a captured suit keeps its roster durability (every hit
  while captured goes into Ultron's override shell), and is handed back on liberation, node loss,
  event end, owner logout or cleanup.
- Ultron's lines: only `HeroSpeech` subtitles (new non-player "world voice" path), never chat.
  Russian is the reference text; all 12 locales get real translations.
- Adaptation only uses what the machines really observed: hits taken (attacker geometry), sensor
  and unit line of sight, node losses, repelled attacks. Sensors offline = adaptation frozen.

## Phases

| Phase | Length | What happens |
|---|---|---|
| AWAKENING (Пробуждение) | 70–110 s | Glitch pulses, the core node boots, first drones scan, Ultron's first lines |
| SPREAD (Распространение) | 3–5 min | Engineers raise new nodes on scenario sites, links light up, foundries start; players discover / disable / destroy nodes |
| MACHINE_WAR (Машинная война) | 4–6 min | Role coordinator: recon, defense, assault, repair, intercept, factory guard; doctrine choice and switches |
| ADAPTATION (Адаптация) | 3–5 min | Protocols from observed tactics: ANTI_AIR, DEFLECTOR, RELOCATION, REDISTRIBUTION, FORTIFY (max 3, cooldowns, counters) |
| FINALE (Финальный Альтрон) | until win / upload | Ultron Prime assembles at the strongest node; stages TACTICAL → AERIAL → OVERDRIVE; live nodes tether buffs; upload timer = defeat |

Phase changes are time + condition based (network size, losses, adaptation pressure), with min and
max lengths per scenario.

## Network

Node kinds: CORE (root, uplink + power), UPLINK (controls machines, captures golems / Legion suits in range),
FOUNDRY (produces units), BULWARK (shields neighbours and units), SENSOR (recon, feeds intel, drives adaptation),
REPAIR (repairs nodes and units, sends engineers). Links: each node links to its nearest powered nodes
(max 3); power flows from the core over online links (BFS), so cutting a hub isolates its branch.
Node states: PLANNED → BUILDING → ONLINE ⇄ DISABLED → DESTROYED.
Player interaction: discover (close with line of sight, or intel salvaged from a downed drone),
disable (sneak + use at the core for 3 s → offline 60 s, engineers can reboot sooner),
destroy (shield then hull; bulwarks regenerate shields).

Attacks use timed actions (anticipation → acceleration → contact → follow-through → recovery); the
server applies damage, sound and FX on the clip's contact tick.

## Scenarios (seeded, reproducible)

`UltronScenario.of(seed)`: variant (QUIET_INFECTION Тихое заражение, FACTORY_WAR Заводская война,
HUNTER Охотник, SINGULARITY Сингулярность), node layout (RING / CHAIN / CLUSTER / SCATTER, angles and
radii), node kind plan, unit composition weights, doctrine weights, assault routes, attack style,
Ultron's boss style and the finale condition (upload length, boss spawn rule, tether kinds).
Same seed → same plan.

## Network packets

`UltronStateS2CPacket` (phase, clocks, doctrine, scenario, nodes with links and states, protocols,
finale timer, boss id, own hack progress; resent on login / dimension change / respawn) and
`UltronFxS2CPacket` (impacts, blasts, shields, node boot / break, fabrication, glitch pulses, tethers).
