# Reinhard — secret ability THE FINAL PUNCH

Branch `feat/reinhard-final-punch-20261031`. A hidden 24-second cinematic finisher for Reinhard
(any mode). Server: `hero/reinhard/finalpunch/*`; client: `client/reinhard/finalpunch/*`,
`client/reinhard/FinalPunchPose.java`; body take: `animations/reinhard/final_punch.animation.json`
(generated by `tools/assets/make_reinhard_final_punch.py`); sounds: `tools/sfx/reinhard_final_punch.py`
(13 own procedural CC0 cues, `sound-overlays/reinhard_final_punch.json`); text:
`lang-overlays/reinhard_final_punch/<12 locales>.json`.

## Trigger and targets
- **Shift + N** (Shift + the slot-6 hero key). N alone keeps the normal slot-6 ability: with Shift held
  `FinalPunchInput.intercept` swallows slot 6 and the chord edge sends `ReinhardFinalPunchC2SPacket(hint)`.
- Client gate (same `ReinhardActions.gate` as the other actions): alive, not spectator, not anchored,
  cooldown (`message…final_punch.cooldown`), busy (`…busy`), no target (`…no_target`).
- Look pick `FinalPunchTargets.pick`: valid entry, line of sight, ≤ 16 blocks, ≤ 28° cone, angle first.
  Targets: players, villagers, wandering traders, citizens, Avengers (HUMAN) and iron golems (GOLEM).
- Server re-validates (`FinalPunch.valid`, `withinGrace`), places the target face to face on the fist line
  (`anchor`, `jawPoint`), acquires a FREEZE control (ControlManager), starts action FINAL_PUNCH for 480 ticks,
  sets the cooldown (config `reinhardFinalPunchCooldownSeconds`, default 300 s) and records the discovery
  (`HeroSecrets`, persisted player NBT `viltrumitecore:secrets`; a future gallery lists only discovered secrets).

## Body take
`make_reinhard_final_punch.py` keeps pose keys, eases between them, solves planted feet with a two-bone leg
IK on every sample (the right sole drifts 0.01 px over 24 s) and solves the contact arm onto the jaw point
(fist centre 0.863/1.436/0.132 vs target 0.87/1.44/0.13 forward/up/right). Golem jaw (2.06 m): from 404 to
474 `FinalPunchPose.aim` jumps 8.5 px, drifts 2.08 px forward and raises the arm 20.6° (fist 2.087 m).
`FinalPunchPoseTest` re-checks all of it on the Java rig; `--check` keeps JSON and the fallback fist table
(`FinalPunchFist`) in sync. During the take Reid rests in its sheath and held items are hidden.

## Network
S2C `ReinhardFinalPunchS2CPacket` to tracking + self: START (jaw point, facing), IMPACT at 444 (also to the
victim; late joiners build the scene from it), CANCEL only on a forced end. A normal end sends nothing: each
client ends at 480 + 24-tick tail. Every client derives everything from the scene clock, so two clients see
the same take, the same chaos and the same jaw path (seeded by caster/target/yaw).

## Safety and cleanup
Server `FinalPunch.cancel` (CleanupReason: death, logout, dimension change, target lost/removed, forced end,
server stop) releases the control, interrupts the speech and broadcasts CANCEL. Client: CANCEL → 10-tick fade,
sounds stopped and the duck released; level change, logout, world unload → `clearAll` + jaw pieces cleared;
caster missing 40 ticks → end; local death → cancel; pause-aware. The jaw/wound are temporary visuals
(≤ 30 s). The camera, mouse and movement locks exist only while a scene exists.
