# Тор (God of War Ragnarök): дизайн героя

> Дата: 2026-10-27. Источник: идея пользователя; ассеты — архив пользователя `GoW_Thor_Kratos_assets` (God of War HeroPack 3.0.0, SymbioteSpidey).
> Статус: этап 1 (фундамент) реализован. Этапы 2–8 — направление; числа и детали согласуются перед каждым этапом.

## 1. Рамки
- Фантазия: громовержец с Мьёльниром — удары молотом и кулаками, бросок и возврат, электрический режим, рывки-молнии, захваты, добивания, ульта.
- Этап 1 — только фундамент. Работает: выбор героя, скин, борода/живот, Мьёльнир на поясе или в руке, СКМ — достать/убрать.
- Остальные приёмы разрешаются по контексту, но явно отказывают: «<приём>: в разработке (этап N)» + звук отказа. Заглушек с эффектом нет.
- Шасси ванильное: без кита Viltrumite, без полёта, без пассивов.
- Тики: 20 = 1 с.

## 2. Как стать героем
Кнопка «Стать Тором» на экране выбора (`/viltrumite choose` открывает его снова). `enter`: молот на поясе, обычный режим, приём сброшен, в чат — подсказка управления.

## 3. Скин и модель
- Скин 64×64: склейка `thor_layer1` + `thor_layer2` (TechnoGhosty).
- Борода и живот (FatherKhimsky) — geo на голове и теле, только 3-е лицо; живот скрыт под нагрудником.
- Мьёльнир (Szombie) — geo в двух точках: правая рука (`mjolnir_hand`) и правое бедро (`mjolnir_belt`). Масштаб 0.45 вшит в кубы, box UV → per-face UV. Текстура 512 → 256 px (лимит 64 КБ на запрос GitHub MCP). Руны светятся всегда (glow-проход).
- `MjolnirPlace`: HAND — молот в руке и правая рука пуста; BELT — иначе (предмет в руке всегда побеждает); HIDDEN — брошен (этап 3).
- Позы (3-е лицо): удержание −18°, клипы DRAW/HOLSTER в `ThorClips` на часах снапшота. Новый приём = тики на сервере + клип в `ThorClips`; `ThorPoser` не меняется.

## 4. Управление (контекстное, `ThorControls`)
Один резолвер на сервере (нажатие), на клиенте (перехват мыши) и в панели (серые слоты).

| Ввод | Клавиша | Контекст → приём (этап) |
|---|---|---|
| STRIKE | ЛКМ | захват+присед → FATALITY (6); захват → GRAB_SLAM (5); блок → HAMMER_THROW (3); полёт → AIR_STRIKE (4); электро → ELECTRIC_COMBO (3); молот в руке → HAMMER_COMBO (2); иначе FIST_COMBO (2) |
| STANCE | ПКМ | молот в руке → GUARD (2); есть цель → GRAB (5); иначе ваниль |
| HAMMER | СКМ (клавиша «сердце») | на поясе → DRAW (1); в руке → HOLSTER (1); брошен → RECALL (3) |
| POWER «Гром» | R | электро + молот в руке + не присед → LIGHTNING_CALL (3); иначе ELECTRIC_MODE (3) |
| MOBILITY «Натиск» | Y | в воздухе → DIVE_SLAM (4); есть цель → TELEPORT_STRIKE (4); иначе LIGHTNING_DASH (4) |
| ULTIMATE «Гнев Тора» | Z | WRATH (7) |

- Мышь перехватывается, только если её приём выпущен: на этапе 1 только СКМ. ЛКМ/ПКМ/F — ваниль до этапа 2. ЛКМ по блоку ломает блок всегда.
- R/Y/Z серые; нажатие → отказ «в разработке». Нажатие во время приёма, который не уступает → «идёт другой приём».
- `hasTarget/flying/guarding/grabbing` пока всегда false (появятся в этапах 2/4/5).

### 4.1 Достать / убрать Мьёльнир (этап 1)
- Условия: жив, не заякорен; для DRAW правая рука пуста (иначе «Правая рука занята»).
- Фазы 4/2/4 т: тянется к бедру → хват (молот меняет место в начале MAIN) → доводка. В FINISH следующее нажатие отменяет доводку.
- Предмет взят в руку до хвата → DRAW прерван. Предмет в правой руке при молоте в руке → молот сразу на пояс.
- Якорь/смерть → приём прерван. Звуки ванильные: ARMOR_EQUIP_NETHERITE (достать), ARMOR_EQUIP_CHAIN (убрать).

## 5. Общие системы (`hero/combat/`)
### 5.1 Поэтапные приёмы — `StagedTimeline`
- Фазы INTRO → MAIN → FINISH; фаза с 0 тиков пропускается; приём без тиков не стартует.
- Приоритет выше — прерывает ниже вне окна отмены; равный — нет. В окне (`cancellableFrom`) прерывает любой.
- Комбо: `maxSteps`; одно нажатие буферизуется до окна, в окне — сразу следующий шаг.
- Гиперброня: `resists(reason, phase)`; LIFECYCLE не сопротивляется никогда.
- Парные приёмы: без партнёра — отказ; партнёр в `controlTargetId`, одни часы — снапшот владельца.
- Снапшот: `actionId` = wire id, `actionElapsed/Length`, `variant` = фаза | шаг<<2.
### 5.2 Взаимодействие оружия — теги
- Герой публикует `CombatPresence` (id, теги, стойка, приоритет) через `HeroDefinition.combatPresence` (по умолчанию NONE).
- Теги иерархические (`weapon` совпадает с `weapon.hammer`). Правила называют только теги и стойки, симметричны; выбор: приоритет → специфичность → порядок регистрации.
- `defaults()`: clash (оружие ACTIVE × ACTIVE), block (ACTIVE × оружие GUARD), block_bare (тело ACTIVE × оружие GUARD). Особые встречи — новые правила с более глубокими тегами, не проверки пар героев.
- Мьёльнир: weapon.hammer, element.lightning, trait.divine/throwable/returning/unbreakable; кулаки: body.bare. К попаданиям не подключено (этап 2).

## 6. Жизненный цикл
NBT `Thor/Hammer` — только место молота (брошенный при загрузке → в руке, неизвестное → пояс). Режим и приём не сохраняются. Респаун и стирание — молот на поясе. Смена измерения/героя, выход — приём остановлен.
