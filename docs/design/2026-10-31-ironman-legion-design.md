# Железный человек — этап 6: «Железный легион» (дизайн)

Статус: принят пользователем как постановка задачи (ТЗ этапа 6). Этот документ фиксирует, *как* ТЗ ложится на код.
Предыдущие этапы: `docs/design/2026-10-09-ironman-design.md` (§6.2 резерв слота, §12.6, §19–§20).

## 1. Идея для игрока

Тони вызывает до трёх свободных костюмов из ростера «Вероники». Они прилетают с неба разными траекториями,
тормозят, разворачиваются, занимают позиции вокруг владельца, каждый делает короткую «готовность» и переходит
в режим охраны. Дальше костюмы действуют сами, но слушают приказы: «Следовать», «Охранять», «Атаковать»,
«Держать позицию», «Вернуться». Каждый Mark воюет по‑своему (своя специализация из этапа 4).

## 2. Ростер и владение

- `MarkLocation` получает пятое значение `LEGION` (append‑only, NBT хранит имя — старые миры совместимы).
- Марк в мире существует ровно в одном виде: `WORN`, `EMPTY`, `IN_DELIVERY` или `LEGION`. Все переходы — через
  `MarkRoster.move(id, from, to)`, который отказывает, если марк не там, где ожидается.
- В Легион можно вызвать только марк `STORED`, без перезарядки поломки и с прочностью > 0 (`MarkRoster.legionCallable`).
  Надетый, пустой и доставляемый костюмы недоступны. Максимум 3 (`LegionRules.MAX_SUITS`).
- Прочность костюма Легиона живёт в ростере (`Entry.durability`): урон по сущности сразу списывается в ростер
  (`MarkDamage.apply` с бронёй/обшивкой марка). Сущность лишь показывает значение. Возврат не лечит, повторный вызов
  не создаёт копию: прочность берётся из ростера.
- Поломка (прочность 0) → аварийное падение (≈2 с, искры, сбои двигателя) → `breakMark` (STORED, перезарядка 6000 т).
- `recallWorld()` возвращает `LEGION` в `STORED` вместе с `EMPTY/IN_DELIVERY` — это покрывает загрузку, релог,
  смерть, смену героя, смену измерения, остановку сервера (сущности Легиона не сохраняются в чанке).

## 3. Вызов

- Способность `ironman:legion` («Железный легион») — страница 2, свободный 6‑й слот (индекс 11). Действие `HeroAction.LEGION`.
- Нажатие без Легиона в мире → экран выбора (`LegionScreen`): карточки доступных марков в стиле «Вероники»
  (голо‑стекло, вращающееся превью, прочность, роль), выбор до 3, кнопка «Вызвать». Сервер повторно проверяет
  выбор (`LegionCall.validate`), отбрасывает дубли/лишние/недоступные.
- Нажатие с Легионом в мире → тот же экран в режиме приказов (кнопки 1–5 + приоритет цели). Пока «Вероника»
  доставляет/забирает костюм (`IN_DELIVERY`/капсула в пути) — вызов отклоняется сообщением и звуком отказа.
- Кулдаун вызова — `extraCooldowns[4]` (≈10 с после возврата всего Легиона), отображается серым слотом.

### Последовательность прибытия

1. JARVIS: «Легион активирован.» (+ «Три костюма в вашем распоряжении, сэр.», если костюмов три).
2. Сигналы подлёта: далёкий нарастающий гул и световые следы в небе (≈1,5 с).
3. Костюмы появляются в 40–60 блоках выше и сбоку, каждый со своей стороны, и летят по кривой Безье
   (разные контрольные точки: пике, широкая дуга, низкий заход) к своему месту строя.
4. Торможение: разворот ногами вперёд, вспышка репульсоров, звук торможения, зависание/приземление.
5. Индивидуальная «готовность» (≈1 с) — своя анимация у каждой специализации.
6. Режим `GUARD`.

## 4. Приказы

`LegionOrder`: `FOLLOW` (строй за спиной, атакует только угрозы владельцу), `GUARD` (по умолчанию: кольцо вокруг
владельца, перехват угроз в радиусе 16), `ATTACK` (цель из прицела владельца; если нет — текущая угроза),
`HOLD` («Держать позицию»: точка в прицеле, радиус 10), `RETURN` (улетают вверх и возвращаются в Веронику).
Приказ может быть общим или для одного костюма. Приоритет цели: «Ближайшая угроза», «Сильнейшая», «Цель Тони».

## 5. ИИ

### Координатор (`LegionSquad`, один на владельца)
- Каждые 10 т собирает «доску угроз» (`ThreatScore`): кто бьёт владельца/костюмы (память 200 т), опасность
  (враждебность, урон, класс моба), дистанция, видимость (луч до глаз), здоровье и броня цели, выбранный приоритет.
- Распределяет роли (`LegionTactics.assign`): `VANGUARD` (фронт), `FLANKER` (обход с боку), `OVERWATCH` (сверху),
  учитывая специализацию. Не даёт всем лупить одну слабую цель (оценка «перебора» по ожидаемому урону).
- Перехват: если кто‑то бьёт Тони, ближайший исправный костюм прерывает свою задачу и защищает его.
- Тяжёлое оружие не применяется по цели, которую добьёт обычный выстрел, и если рядом владелец/союзники.
- Повреждённые (< 30 %) — отступают на дистанцию/вверх, при < 12 % — возвращаются в Веронику (с репликой JARVIS).
- Пересчёт размазан по тикам: тик костюма — каждые 2 т со сдвигом по слоту, координатор — каждые 10 т со сдвигом по владельцу.

### Поведение костюма (`LegionSuitBrain`)
- Никогда не атакует владельца, другие костюмы Легиона, защищённых союзников (`IronManTargets`/`ServerRules`),
  жителей и нейтральных мобов без приказа `ATTACK`; игроков — только если сервер разрешает PvP.
- Единое правило урона в `LivingAttackEvent` дополнительно гасит любой урон Легиона по своим (включая сплэш ракет).
- Оружие: репульсоры (общий `RepulsorBlastEntity` с владельцем‑сущностью), микроракеты (`MicroMissileEntity`), сигнатура
  марка через «ядра» сигнатур этапа 4 (общий код с игроком, без копий).

| Mark 42 | манёвр | ракетный кулак (снаряд‑рука) | частые уклонения, фланг |

## 6. Полёт (`LegionSteering`, чистая математика)
- Желаемая скорость → ограничение ускорения/торможения (плавные разгоны), наклон корпуса по ускорению.
- Строи: «клин» (FOLLOW), «кольцо» (GUARD), «тройка» над точкой (HOLD).
- Обход препятствий: 3 «щупа» (прямо, ±35°) лучами по блокам, подъём над крышами, скольжение вдоль стен.
- Разведение костюмов (separation), боевая дистанция по оружию, обход по кругу (страфы), уклонение от снарядов
  (боковой рывок по перпендикуляру к снаряду), погоня за летающими.
- Анти‑застревание: если 60 т прогресс < 1 блока — подъём и смена стороны; телепорт только как последнее средство
  (> 64 блоков от владельца, не чаще раза в 10 с).

## 7. Визуал и анимация
- Рендер `LegionSuitRenderer` на базе модели пустого костюма (`empty_suit.geo.json`), кожа/свечение марка
  (`MarkTextures`), детали марка (`MarkExtras`), пламя `ThrusterFlames`.
- Поза — клипы `legion_suit.animation.json` через существующее ядро `client/anim` (AnimCache/AnimationController)
  + процедурные слои (наклон, поворот торса и прицел одной/двумя руками) поверх, как в правилах skill.
- Клипы: запуск двигателей, вертикальный взлёт, переход в горизонтальный полёт, торможение/зависание, поворот торса,
  прицел, пуск ракет, уклонение, реакция на попадание, аварийное падение, приземление, «готовность» ×7.
- Эффекты: энергетические следы, вспышки выстрелов, искры, лучи; критический урон → прерывистое пламя,
  дым/искры, неустойчивый полёт.

## 8. Звук и JARVIS
Свои синтезированные звуки (ffmpeg), без ванильных заглушек: старт двигателей, гул полёта (петля), торможение,
приземление, сервоприводы, репульсор Легиона, сигнал подлёта, сбой двигателя. Субтитры во всех локалях.
JARVIS (короткие, без повторов через `VoiceGate`): «Легион активирован.», «Три костюма в вашем распоряжении, сэр.»,
«Обнаружена угроза. Перехватываем.», «Один из костюмов получил критические повреждения.», «Возвращаю Легион в Веронику.»

## 9. HUD
Компактная колонка у правого края: три строки «Имя марка · полоса прочности · состояние · приказ». Скрывается,
когда Легиона нет; не перекрывает основной HUD Железного человека.

## 10. Жизненный цикл
| Событие | Поведение |
|---|---|
| смерть владельца | все костюмы исчезают в тот же тик, прочность в ростере, LEGION → STORED |
| выход/вход | сущности не сохраняются; `recallWorld` при загрузке |
| смена героя / снятие костюма | `cleanup` → отзыв |
| смена измерения | отзыв |
| остановка сервера | сущности не сохраняются, ростер уже корректен |
| костюм уничтожен | падение → `breakMark` |
| костюм вернулся | улетает вверх, LEGION → STORED |
| вызов во время действия Вероники | отказ |
| одновременные приказы | последний выигрывает, обработка на серверном тике |
| второй игрок зашёл позже | синхронизация сущностей стандартным трекингом |
| владельца нет в мире / не Тони | сущность сама удаляется в первый тик без владельца |

## 11. Ограничения
- Никаких фейковых игроков; `MarkSignature` остаётся для игрока, общие части выносятся в «ядра», которые
  принимают `SuitActor` (игрок или костюм).
- Код Легиона живёт в `hero/ironman/`, `client/ironman/`, `entity/`.
