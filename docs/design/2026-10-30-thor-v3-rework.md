# Тор v3: переработка «ощущения» (design spec)

> Дата: 2026-10-30. Автор решений: агент, по прямому поручению владельца («доверяю переработку, способности
> придумай сам, всё делай сам»). Основа: PR #85 (ZIP v2). Дополняет `2026-10-27-thor-design.md` и
> `2026-10-28-thor-rework.md`; где этот документ им противоречит — побеждает этот.

## 0. Почему Тор ощущается хуже DIO / Синклера / Сон Джину (аудит 2026-10-30)
1. Нет характера: у Тора нет ни одной реплики, субтитра, портрета (`lines()` пуст), у остальных — есть
   сигнатурный момент с репликой и 3D-портретом.
2. Непредсказуемое управление: СКМ решает по контексту (захват → возврат → *враг в 4 блоках → удар* →
   иначе бросок). Бросить молот рядом с мобом нельзя. На панели пусты слоты B и N.
3. Модель статична: борода и живот анимированы в 1 клипе из 119, голова — в 2; вторичной динамики нет.
4. Тело и клипы: 19 костей / 35 кубов, текстура 128×64 на 3.15-блочном теле; клипы печёт решатель
   с приоритетом «без проникновений», а не выразительности.
5. Процесс: 109 коммитов разных сессий, почти всё «без игры».

## 1. Решения (что меняется)
### 1.1 Управление — каждая кнопка делает одно
| Ввод | Было | Стало |
|---|---|---|
| ЛКМ | лёгкая цепочка (молот / кулаки / электро) | без изменений |
| ПКМ | тяжёлая цепочка; в электро-режиме волна / буря | без изменений |
| СКМ | захват / возврат / удар (враг ≤ 4 бл.) / бросок | **только молот**: окно захвата → захват; молот не в руке → возврат; иначе **бросок** (удержание = заряд). Ветки «враг рядом → удар» больше нет |
| R | Громовая сила (электро-режим) | без изменений |
| Y | Натиск (к брошенному молоту) | без изменений |
| Z | Гнев (ульта) | без изменений (клавиша владельца) |
| V | Биврёст (телепорт) | без изменений |
| B | — | **«Сокрушение»** (`thor:crush`): бывший удар СКМ (`HAMMER_STRIKE`: размашистый удар → добивание в землю). Только с молотом в руке |
| N | — | **«Громовой раскат»** (`thor:thunderclap`), этап 1b (см. §2) |

Слоты B/N используют уже существующие действия `HeroAction` (только как идентификаторы ввода Тора):
маршрутизация идёт через `ThorHero.handleInput` текущего героя, другим героям они не приходят.

### 1.2 Голос и портрет
Свои реплики (оригинальный текст, не цитаты из игры), субтитры `subtitle.viltrumitecore.thor.*`,
говорящий «Тор», 3D-портрет — бюст собственной модели (голова, борода, плечи), как у Рейнхарда / Джину.

| Событие | Реплика (ru) | Приоритет |
|---|---|---|
| Гнев (ульта), 3 страницы | «Небо, слушай меня!» / «Вы хотели увидеть бога грома?» / «Так смотрите!» | ULTIMATE |
| Биврёст | «Биврёст! Открой путь!» | ABILITY |
| Бросок молота (не чаще 30 с) | «Мьёльнир!» | ABILITY |
| Сокрушение (не чаще 20 с) | «На колени!» | ABILITY |
| Электро-режим включён (не чаще 30 с) | «Гром со мной.» | ABILITY |

### 1.3 Живое тело (без новых систем)
Процедурная вторичная динамика поверх клипа в `ThorBodyPose`: борода — пружина по ускорению и повороту
корпуса, живот — затухающий отклик на шаги и удары; голова следует взгляду камеры, если клип её не держит.

### 1.4 Что не меняется
Размер и хитбокс (3.15 × 2.0, решение владельца: хитбокс = модель), урон, кулдауны, механики молота,
сцены, полёт, тайминги ударов (цепочка отменяется в фазу восстановления: реальный ритм молота
13–15 т, кулаков 9–11 т).

## 2. Этапы
- **1a (этот PR):** §1.1 (СКМ, «Сокрушение»), §1.2, §1.3, иконки, строки 12 языков, тесты, проверка в клиенте.
- **1b:** «Громовой раскат» (N): Тор вбивает Мьёльнир в землю, кольцо молний 6 бл., оглушение 1 с,
  отброс; свой клип, звук, VFX, кулдаун 12 с.
- **2:** клипы по ключевым позам (выразительность первична, решатель — только проверка), тяжёлые удары
  с хит-стопом, лёгкие быстрее.
- **3:** модель и текстура: кисти с пальцами, наручи, пояс, коса бороды на пружине, текстура 256×128.

## 3. Приёмка этапа 1a
- СКМ рядом с врагом бросает молот; удар по врагу — клавиша B.
- Каждая реплика из §1.2 показывает субтитр с портретом Тора; портрет — модель Тора, не скин игрока.
- Борода и живот заметно реагируют на ходьбу, повороты и удары (сбоку, 3-е лицо).
- `./gradlew build` зелёный; выделенный сервер до `Done`; проверка в клиенте (Xvfb) со скриншотами.
