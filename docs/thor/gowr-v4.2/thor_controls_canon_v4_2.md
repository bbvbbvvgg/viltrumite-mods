# THOR — точное исправление управления и запрет лишних способностей (v4.2)

Проверенная база репозитория: `feat/thor-foundation` @ `3c233edc3e480aa84d916e4a39b1507945ec34e1` на момент проверки. **Файлы в комплекте — исправленные ТЗ, не изменения кода GitHub.**

## Что было ошибочно в раннем фундаменте (исторические проблемы, исправлены к BASE_SHA)

- `ThorControls.resolve(STANCE)` даёт `GUARD` по ПКМ с молотом — **запрещено**. ПКМ — часть обычных/электрических комбо и контекстных взаимодействий, не блок.
- `ThorControls.resolve(HAMMER)` даёт `DRAW/HOLSTER` по СКМ — **неверно**. СКМ = захват > отзыв > ближний удар > бросок. Не назначать отдельную кнопку для DRAW/HOLSTER.
- `ThorControls.resolve(POWER)` даёт `LIGHTNING_CALL` в электрическом режиме — **неверно**. R всегда переключает режим, а небесный удар автоматически завершает успешное электрическое комбо.
- `ThorControls.resolve(MOBILITY)` даёт `LIGHTNING_DASH`, `TELEPORT_STRIKE`, `DIVE_SLAM` по Y — **неверно**. Y = только притяжение Тора к уже летящему после броска молоту (решение №220); V = камера телепортации; двойное WASD = рывок.
- `ThorControls.resolve(STRIKE)` допускает `AIR_STRIKE` в полёте, `HAMMER_THROW` при guard, `FATALITY` при sneak+grab — **неверно**. В полноценном полёте атак нет, бросок только через контекст СКМ, фаталити только от смертельного удара Мьёльниром в руке по игроку/герою.
- `ThorAbilities.THUNDER`, `ONSLAUGHT`, `WRATH` и `ThorMove.WRATH` — существующие **технические идентификаторы**, а не утверждённые автором названия или набор отдельных умений. Одобрена **одна концентрированная ульта** на отдельной клавише, точная клавиша и название пока не утверждены. Z — временный дефолт.

## Каноничная раскладка

| Ввод | Действие |
|---|---|
| ЛКМ/ПКМ | Обычные контекстные комбо; в режиме молний — разряд/волна; удержание ПКМ — расширяющаяся гроза |
| СКМ | Окно захвата → захват; молот вне руки → отзыв; враг в 4 блоках → удар по направлению взгляда; иначе → бросок; удержание в контексте броска → зарядка |
| R | Вкл./выкл. электрический режим |
| V | Камера выбора точки телепортации, ЛКМ подтвердить, Escape отменить |
| Y | Притяжение к летящему после броска Мьёльниру, не к лежащему |
| Двойное WASD | Рывок на земле или при зависании |
| Отдельная клавиша (ещё не решена) | Ульта: вся мощь в одну точку |

**Не добавлять новых способностей, клавиш, боевых режимов или скрытых контекстов.** Для старых enum ID допустимо сохранение неактивных значений ради стабильности wire ordinal; никакого автоматического включения по `SHIPPED_STAGE`.
