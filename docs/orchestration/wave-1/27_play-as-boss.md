## Для игрока
Один игрок становится Годзиллой, Таносом или Альтроном. Остальные — герои, которые должны его остановить. Асимметричный мультиплеер, о котором будут рассказывать.

## Обязательно
1. **Вселение:** игрок управляет сущностью босса (камера, движение, атаки на хотбаре и клавишах), ИИ босса при этом на паузе; камера подстроена под масштаб гиганта.
2. **Три босса:** Годзилла (атомное дыхание, удар хвостом, топот, рёв), Танос (камни Перчатки), Альтрон (дроны, лучи) — на их существующих атаках.
3. **Правила режима:** команда настройки матча, здоровье босса масштабируется по числу героев, условия победы, возрождение, HUD.
4. **Надёжность:** при дисконнекте игрока-босса возвращается ИИ, никаких дубликатов, всё работает на dedicated server.
5. **Интерфейс «боссом может управлять игрок»** — для боссов волны (Сукуна, Траг, Галактус).

## Плейтест
- Каждый босс под управлением игрока против второго игрока-героя (dedicated server + 2 клиента), дисконнект посреди матча.

## Готово, когда
- Играть боссом весело и мощно, а матч остаётся честным.
