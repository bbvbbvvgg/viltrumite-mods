## Для игрока
Удар в небоскрёб: летят куски бетона, стекло осыпается дождём, пыль закрывает улицу, здание проседает и рушится с задержкой. Остаются кратеры и пожары. А `/city reset` возвращает всё на место.

## Обязательно
1. **Падающие фрагменты:** оторванные группы блоков становятся падающими сущностями — сталкиваются, бьются дальше, наносят урон.
2. **Стекло** лопается волной по радиусу ударной волны; **пыль**, **дым** и **огонь** — в бюджетах (A13).
3. **Структурная целостность:** здание без опор проседает и обрушается поэтапно (развитие существующего обрушения).
4. **Кратеры и подпалины** — через журнал (A8).
5. **API для способностей:** обратная совместимость с текущими разрушениями героев (`HeroDestruction`, `CarveJobs` — проверь точные имена в коде); новые возможности герои подключают по желанию.

## Плейтест
- Atheria: удары разными героями, обрушение здания, `/city reset`; FPS и TPS 20+ минут; dedicated server + 2 клиента.
