## Для игрока
Город живёт: ограбление банка, захват заложников, пожар в высотке, падающий самолёт, автобус на краю рушащегося моста. Успел — город тебя любит. Разрушаешь — ты угроза. Жители аплодируют, снимают на телефоны или в ужасе бегут.

## Обязательно
1. **Режиссёр происшествий:** запускает происшествия рядом с игроками с интервалами и встаёт на паузу во время мировых событий. 6 типов: ограбление банка, заложники, пожар в здании (спасение с этажей, огонь через журнал), падающий самолёт (поймать и посадить), обрушение моста с автобусом, цепочка взрывов газа.
2. **Спасение:** общий API «нести жителя» для героев, тушение (лёд, вода, ветер — по флагам способностей), ловля тяжёлых объектов.
3. **Репутация:** шкала «герой ↔ угроза» у каждого игрока; реакции жителей (аплодисменты, поза «снимает на телефон», бегство, брошенные предметы), реплики и субтитры.
4. Награды и задел для Кодекса и достижений.
5. События изменения репутации опубликованы для других систем.
