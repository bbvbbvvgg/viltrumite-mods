## Для игрока
В 2.0 есть то, о чём не пишут в описании: редкие встречи, скрытые боссы, пасхалки и достижения за безумные поступки.

## Обязательно
1. **Дерево достижений «viltrumite 2.0»:** 30+ достижений про героев, события и город, с иконками и локализацией.
2. **5 секретов** со своими условиями появления — придумай сам, оригинально и в духе мода. Например: Наблюдатель появляется над городом после события без единой смерти; кровавая луна с особыми мобами; ритуал, открывающий скрытого босса.
3. **Скрытые облики героев** (только косметика, через `CosmeticLoader`) — награда за секреты.
4. Подсказки игроку — только загадочные; полный список секретов — в PR и документации для оркестратора.
5. Категория «Секреты» в Кодексе — по контракту сессии 04 (опиши свою часть).

## Плейтест
- Каждый секрет вызывается своим условием; достижения открываются на dedicated server + 2 клиента.
