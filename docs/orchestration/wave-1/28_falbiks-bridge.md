# Сессия 28 — falbiksheroes: мост 2.0 и межмодовые взаимодействия

> Сначала прочитай `00_RULES.md` — он обязателен. Здесь только твоя задача.

- **Ветка:** `wave1/28-falbiks-bridge`
- **PR:** `[2.0·28] Мод друга: мост 2.0 и взаимодействия героев двух модов` → `integration/viltrumite-2.0`
- **Зона:** новый `compat/falbiks/` — обобщение `compat/spider` без поломки текущего моста; оверлеи `falbiks_compat`.

## Для игрока
Герои друга и герои viltrumite наконец «знают» друг о друге: реагируют на атаки, делают совместные приёмы, боссы viltrumite замечают героев falbiks, а когда установлены оба мода — случается секретная встреча вселенных.

## Обязательно
1. **Исследование** `original-jars/falbiksheroes-forge-0.4.0-prebeta.474.jar` (не изменять, код и ресурсы не копировать): герои, сущности, предметы, способности, события и точки расширения — по списку классов и сигнатурам. Документ `docs/compat/falbiks-0.4.0-prebeta.474.md`. **Список героев falbiks опубликуй в PR в первый час** — сессии 05–11 сверяются с ним, чтобы не дублировать героев друга.
2. **Мост 2.0:** `FalbiksBridge` (ничего не делает без мода), обнаружение через ModList, проверка версии, рефлексивная проба — для всех найденных героев, а не только паука.
3. **8+ взаимодействий:** реакции героев двух модов друг на друга, совместные приёмы, реакции боссов (Танос охотится за героем falbiks), жители узнают героев друга.
4. **Секретное событие «Встреча вселенных»** (только при обоих модах): разлом в небе и совместная встреча с боссом.
5. **Тесты** по образцу `FalbiksJarSignatureTest` (`./gradlew test -PfalbiksJar=<путь>`); запуск с модом и без него; dedicated server + 2 клиента, один из игроков — герой falbiks.
