- **Зона:** новый `saga/`, оверлеи `saga`. Мировые события — только через их API (`WorldEventManager`), без переписывания.

## Для игрока
Не набор случайных событий, а история: метеориты → Читаури → Альтрон → война Таноса → последствия. Режиссёр следит за силой игроков и разрушениями, нагнетает напряжение, вставляет сюжетные сцены, новости и реплики героев.

## Обязательно
1. **Режиссёр:** цепочки событий из data-описаний, правила эскалации (сила игроков, время, разрушения), паузы, соблюдение `WorldEventConflicts`, сохранение прогресса.
2. **Сюжетные сцены:** титры, субтитры, реплики через существующую систему речи, новостные сводки.
3. **Две саги** из существующих событий: «Вторжение» (метеоры → Читаури → война Таноса → последствия) и «Восстание машин» (Альтрон и Т-1000).
4. **Экран прогресса саги**; команды `/saga start|stop|status`.
5. **Контракт:** как новому событию волны встать в сагу (data-запись).

## Если останется время
- Динамическая сложность под состав команды.

## Плейтест
- Сага «Вторжение» целиком на Atheria вдвоём (dedicated server + 2 клиента), рестарт сервера посреди саги.
