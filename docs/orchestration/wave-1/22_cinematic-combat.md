# Сессия 22 — Кинематографичность боя

- **PR:** `[2.0·22] Кинематографичный бой: хит-стоп, камера, ультимейты, добивания` → `integration/viltrumite-2.0`
- **Зона:** `client/cinematic/`, `combat/feel/`, пост-эффекты.

## Для игрока
Каждый удар чувствуется: хит-стоп, тряска, кадр удара, замедление на добивании. На ультимейте камера облетает героя, а ударная волна искажает воздух.

## Обязательно
1. **API ощущения удара:** хит-стоп, профили тряски камеры, кадры удара, экранное искажение от ударной волны. Найди существующие тряски и объедини их, ничего не сломав.
2. **API кинокамеры для ультимейтов:** пути камеры относительно героя, леттербокс, визуальное замедление, пропуск сцены. Затрагивает только кастующего (и согласившихся рядом), безопасно в мультиплеере.
3. **Витрина:** ультимейты 4 существующих героев (Хоумлендер, Тор, Райнхард, Джину) — один вызов API на ультимейт.
4. **Добивания:** цель с малым здоровьем плюс особый ввод → короткая сцена (2 общих и 2 геройских).
5. Настройки «меньше движения камеры» и «без кинокамеры».

## Связи
- 23, 24 и новые герои пользуются твоим API — опубликуй его как можно раньше.

## Плейтест
- 4 ультимейта и добивания на dedicated server + 2 клиента: второй игрок всё видит, а его камеру никто не трогает.
