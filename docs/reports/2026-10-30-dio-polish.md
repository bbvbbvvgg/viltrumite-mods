# DIO / The World — полировка (`feat/dio-polish`)

Дата: 2026-10-30. Ветка от `main` (`cef4eabd`). Ядро **1.55.0**, протокол сети **14** (не менялся: новых пакетов нет, порядок не тронут; в существующем `DioFxS2CPacket` добавлены значения вида эффекта 15 = ROLLER_LEAP и 16 = ROLLER_LAND). Код Тора и Sinclair не менялся; PR #85/#86 не трогались.

## 1. Отладочные команды крови

- `/dio blood fill [цели]` — кровь до 100; `/dio blood infinite on|off [цели]` — бесконечная кровь (уровень оператора 2, `DioCommands`).
- `DioState.infiniteBlood` хранится в NBT и сохраняется после возрождения; в снимке HUD флаг `FLAG_INFINITE_BLOOD`, HUD показывает «∞». Все траты крови идут через `spendAllBlood()` / проверку флага, возврат после отмены ульты при бесконечной крови даёт 100.
- Сообщения: `commands.viltrumitecore.dio.not_dio`, `.dio.blood.fill`, `.dio.blood.infinite.on/off` — во всех 12 языках, в оверлеях `lang-overlays/dio/<locale>.json` (базовые файлы языков больше 64 КБ и не проходят через GitHub MCP, поэтому не менялись).
- Тесты: `DioBloodDebugTest`. В игре: `/dio blood fill` 7 → 100, после остановки времени с бесконечной кровью кровь = 100, `off` выключает, «∞» видно на скриншоте HUD.

## 2. ROAD ROLLER

**Было:** 120 тиков (6 с), прыжок почти не читался, камера игрока не менялась, ролик появлялся «из ниоткуда».

**Стало:** 180 тиков (9 с), фазы (`DioRules.ROLLER_*`): захват 10 → присед 14 → прыжок 26 (вспышка земли, столб пыли, звук прыжка) → появление катка 46 → вершина 60 → зависание 70 (звук падения) → удар 96 → 13 ударов MUDA до 148 → время идёт 160 → DIO приземляется 174. Без телепортов: DIO движется по непрерывной дуге, каток — по `RollerChoreo` (модель не менялась).

- Камера: чистый модуль `client/dio/RollerCamera` (планы, плавные переходы, леттербокс), применяется `RollerCinema` через `DioSceneCameraMixin`; мышь на время сцены заблокирована. План прыжка «догоняет» DIO снизу сбоку.
- На время сцены скрыт ванильный HUD (хотбар, здоровье, еда, броня, воздух, опыт, прицел), панель способностей (`ViltrumiteInGameHudMixin`) и HUD DIO; панель реплик (`HeroSubtitles`) уезжает в нижнюю полосу леттербокса.
- Звук, FX и урон завязаны на одни тики сервера; эффекты рассылаются всем игрокам рядом, звуки катка — `DioSounds.playWide` (радиус ROLLER_RADIUS + 32), поэтому в мультиплеере зрители слышат и видят то же самое.
- Тесты: `RollerCameraTest`, `RollerChoreo`-тесты. В игре: 3 прогона, кадры с первого лица (каждые 4–20 тиков) и с внешней камеры — сцена непрерывна, планы читаются, HUD скрыт, в конце возвращается.

## 3. Звук

- Openverse (API и помощник `download`) во время работы отвечал таймаутами / 504 на все запросы → ни одной CC0-записи взять не удалось. Все звуки DIO — **собственный синтез** (`tools/sfx/dio.py`), лицензия своя, CC0-совместимо.
- Причина «звук плохой»: разброс громкости 13 дБ (knife_hit −17 дБFS, sun_sizzle −22, refuse с пиком −8, удар катка громче удара о землю), один вариант на частые удары, тиканье остановленного времени играло один раз в конце.
- Исправлено: целевая громкость по ролям (`LOUDNESS`: тяжёлые −8…−10, удары −10…−12, движение −11…−15, служебные/петли −15…−17), мягкий лимитер −1.5 дБFS; новые звуки `roller_leap`, `roller_fall`, `roller_land`; варианты `stand_hit_2`, `barrage_hit_2/3`, `knife_hit_2`, `roller_punch_2/3`; переделаны `stand_whoosh`, `knife_hit`, `roller_punch`, `refuse`. Итого 30 событий / 36 файлов, `python3 tools/sfx/dio.py --check` проходит.
- `client/dio/TimeStopClock` — петля тиканья, пока камера внутри действующего поля; стоп/возобновление времени слышны на радиусе поля + 24 (раньше ванильный радиус 16×громкость не доставал до края поля).
- Новые и переделанные события звука лежат в `src/main/sound-overlays/dio/sounds.json`; `processResources` вливает их в `sounds.json` (тот же приём, что lang-оверлеи: базовый `sounds.json` 68 КБ — больше лимита запроса GitHub MCP). Тесты читают через `integration/ShippedSounds`, `check_hero_resources.py` тоже учитывает оверлей.
- Источники/параметры: `tools/assets/dio_sources.md`, `CREDITS.md`. **Не прослушано**: в песочнице нет аудиоустройства (OpenAL не открывается), проверены только файлы, уровни и триггеры.

## 4. Блокировка камеры в The World

- Клиент: `TimeFreezeMouseMixin` + `client/hero/TimeFreezeView` — мышь не вращает камеру замороженного игрока. Сервер: `TimeFreezeMoveMixin` держит сохранённые yaw/pitch (пакеты движения не могут повернуть игрока), `TimeFreezeTeleportMixin`.
- DIO (и исключённые) свободны.
- Снятие: конец поля, принудительный конец, смерть (`TimeStopEvents`: LivingDeathEvent → `DioTimeStop.releaseVictim(..., true)`), возрождение, смена измерения, выход; клиентский сторож снимает блокировку, если 60 тиков нет пакета поля.
- **Найдено и исправлено:** возрождённый ServerPlayer сохраняет UUID и id сущности → старые записи поля снова «ловили» его. Теперь при смерти/возрождении запись удаляется полностью, игрок исключается из этого поля.
- **Найдено и исправлено:** `/kill` по замороженному игроку не убивал — общий `HeroDamage` откладывал урон под контролем с потолком 40 % здоровья. Теперь абсолютный урон (`BYPASSES_INVULNERABILITY`: `/kill`, пустота) не откладывается (`HeroDamage.queuesUnderControl`, тест в `HeroDamageTest`). Обычные удары по-прежнему копятся до конца остановки.
- В игре: заморожен → мышь (рефлексией через `MouseHandler.onMove`) и прямой `setYRot(+90)` не поворачивают (yaw 0.00); после конца мышь снова работает (yaw 30). Смерть во время остановки: hp 0, экран смерти, возрождение — `clientFrozen=false`, мышь крутит (yaw 24). Переход в Энд во время остановки: блокировка снята, мышь работает.

## 5. Универсальная остановка времени

**Корневая причина:** старая остановка правила состояние сущностей (ноль скорости и `noGravity` каждый тик, якорь ControlManager для живых, `+1` к фитилю TNT). Сущности продолжали тикать: ИИ, таймеры, теневые солдаты Цзинь-Ву, способности других героев и игроки двигались/срабатывали, скорости терялись.

**Решение:** общий шов `hero/control/TimeFreeze` (реестр источников, `isFrozen`, `lockedView`). Миксины **пропускают тик** замороженных вместо правки состояния:
- `TimeFreezeLevelMixin` (ServerLevel.tickNonPassenger/tickPassenger) — мобы, тени Цзинь-Ву, снаряды, TNT, предметы, падающие блоки, сущности героев;
- `TimeFreezePlayerMixin` — Player.tick замороженного ServerPlayer (рантайм героя, перезарядки, эффекты);
- клиент: `TimeFreezeClientLevelMixin`, `TimeFreezeRenderMixin` (без интерполяции), камера (§4).
- Скорости сохраняются (`TimeStopField.saved`) и возвращаются в конце, затем добавляется накопленный отброс. Мёртвые не замораживаются. Поле локальное (радиус), вне его ничего не трогается. Принудительный конец/выход DIO/смерть DIO снимают поле.
- Новый герой замораживается автоматически; код нужен, только если у него есть менеджеры уровня вне тиков сущностей.

**В игре (чужая остановка — DIO-FakePlayer, игрок Цзинь-Ву):** 4 тени, зомби, TNT (фитиль держится 70), предмет, песок, стрела, снежок — позиции/скорости/возраст одинаковы в двух пробах через 40 тиков; после конца всё продолжает движение с сохранёнными скоростями (стрела 0.471/−0.057 → 0.457/−0.204, фитиль 70 → 67). Капли крови убитого игрока тоже стоят в поле. Остановка самим DIO: зомби и стрела стоят, DIO свободен.

## Осталось / ограничения

- Не замораживаются менеджеры уровня вне сущностей: сцены Тора/Мьёльнир (код Тора трогать нельзя), World Cut / Saw Sphere Рейнхарда (иначе рассинхрон сцен).
- Часть клиентских визуалов самого замороженного игрока (частицы, анимации рук) продолжает тикать локально.
- Звуки не прослушаны вживую (нет аудиоустройства); CC0-записей нет из-за недоступности Openverse.
- Мультиплеер проверен одним клиентом (чужая остановка — FakePlayer); выход из игры проверен по коду (очистка при logout), не вживую.
