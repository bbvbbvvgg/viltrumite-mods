# Синклер — плейтест в реальном клиенте

Дата: 2026-10-28. Ветка `feat/hero-sinclair`. Итоговый прогон — шестой (проходы 1–5 нашли ошибки, их
исправления ниже).

## Окружение

- Forge 1.20.1, `./gradlew :viltrumitecore:runClient`, JDK 17.0.21 (Temurin).
- Без GPU: Xvfb `:99` (1280×800×24), Mesa llvmpipe — «GL 4.5 Mesa 24.2.6», окно 854×480,
  ~13–19 FPS, сервер 20 TPS.
- Звук: OpenAL Soft через `ALSOFT_DRIVERS=wave` («OpenAL initialized on device Wave File Writer»),
  весь звук клиента записан в WAV.
- `run/options.txt`: язык `ru_ru`, громкость 1.0, `pauseOnLostFocus:false`.

## Метод

Включаемый драйвер `client/sinclair/qa/SinclairPlaytest.java` (только при
`-Dviltrumitecore.sinclair.playtest=true`, иначе не регистрируется). Он создаёт плоский мир, выбирает
Синклера через экран выбора героя и **нажимает настоящие клавиши** (`KeyMapping` зажимается на 3 тика,
ЛКМ/ПКМ — как у игрока): огонь, перезарядка, Vexing Bolt, Саванна и обмен, Rabbit Hex, Misdirection,
захват и все 6 актов. Для съёмки со стороны камера переключается на невидимую стойку-маркер
(`setCameraEntity`), для «вида исполнителя» — обратно на игрока (вид сзади). Цели — кадавры (husk,
без ИИ, 1000 HP) и свинья. Для каждого акта форма задаётся напрямую в состоянии сервера
(`SinclairRepertoire.standard(shape)`), сам акт запускается клавишей ульты. Скриншоты —
`Screenshot.grab` в `RenderTickEvent` (65 кадров), затем клиент закрывается сам.

```
Xvfb :99 -screen 0 1280x800x24 -nolisten tcp &
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 ALSOFT_DRIVERS=wave ALSOFT_CONF=alsoft.conf \
JAVA_TOOL_OPTIONS="-Dviltrumitecore.sinclair.playtest=true -Xmx1700m" \
./gradlew :viltrumitecore:runClient --no-daemon
python3 docs/reports/sinclair-playtest/make_sheets.py viltrumitecore/run/screenshots
```

(`alsoft.conf`: `[wave] file = /data/game_audio.wav`.) Листы — SVG со встроенным WebP: инструмент
публикации ветки передаёт только текст, PNG не загрузить.

## Звук

Слушатель `PlaySoundEvent` в драйвере записал все запрошенные звуки — [sounds_played.txt](sounds_played.txt).
Сыграли 27 из 31 своего звука `viltrumitecore:sinclair.*` (выстрелы ×10, барабанная дробь ×6, поклоны ×6,
все звуки актов, Саванны, гекса, двойника, захвата). Не прозвучали в этом сценарии: `bolt_hit`,
`spark_hit` (снаряды не попали в сущность), `refuse` (не было отказа захвата), `tada`. Ванильные звуки —
только окружение (шаги, свинья, музыка), у Синклера их нет. WAV: 129 с, 102 с с сигналом (RMS > 0.003).

## Найдено и исправлено в реальном запуске

1. Способности не срабатывали от одиночного «клика» — клавиши героя читаются по `isDown`; драйвер держит клавишу (ошибка драйвера, не мода).
2. От первого лица блики у палочки/ладони рисовались огромными квадратами — `SinclairVfx.Ctx.dot` теперь у объектива держит видимый размер (`NEAR = 2`).
3. Конус прожектора — крупные полупрозрачные квадраты → мелкие частицы по 18 образующим + пятно на полу (`StageLight.cone`).
4. При чужой камере (`getCameraEntity() != player`) рисовались руки от первого лица и якоря VFX — исправлено в `SinclairFirstPerson`/`SinclairAnchors`.
5. Вспышка NOVA была одним большим белым квадратом → звёздная россыпь частиц.
6. Ярлык расы ru «Стать Синклером» не совпадал с остальными героями («Рейнхард») → «Синклер».
7. Сценарий: зомби горели на солнце (→ кадавры), гнилая плоть в руке блокировала Prestige (`doMobLoot false`), бродячий слизень из слаймового чанка убил игрока посреди FINALE (→ очистка мобов перед сценой, сопротивление игроку), камера на кроликов ставилась мимо (→ наводится на ближайшую заколдованную сущность).

## Оставшиеся дефекты

- В «виде исполнителя» во время раскрытия NOVA за шляпой видны бледные прямоугольники по её силуэту (кадр 43); со стороны (кадр 42) всё верно. Причина не найдена.
- Ванильная тень полупрозрачного (под вуалью) игрока может оставаться видимой.
- Якоря VFX от первого лица (кончик палочки, ладонь) — оценочные, а не из костей FP-модели.
- В кадрах со стороны виден ник «Dev» (ванильная табличка) и чужие системы мода (кровь от мобов, сообщения «Отряд вилтрумитов…»).
- Панель субтитров (общая система) в третьем лице закрывает центр экрана; замедление во время акта сужает FOV (ваниль).
- llvmpipe даёт 13–19 FPS, поэтому анимации проверены по кадрам, а не по плавности.
