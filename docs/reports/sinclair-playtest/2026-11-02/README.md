# Синклер — плейтест кинематики копирования и новых номеров

Дата: 2026-11-02. Ветка `feat/sinclair-cinematic-polish`, viltrumitecore 1.55.0. Спецификация —
`docs/design/2026-11-02-sinclair-cinematic-polish.md`.

## Окружение и метод

Как в [основном отчёте](../README.md): Forge 1.20.1 `runClient`, JDK 17, Xvfb 1280×800, Mesa llvmpipe
(8–19 FPS, сервер 20 TPS), OpenAL Soft `wave` (весь звук клиента пишется в WAV), язык `ru_ru`, масштаб GUI 2.
Драйвер `client/sinclair/qa/SinclairPlaytest.java` с новым ключом
`-Dviltrumitecore.sinclair.playtest.ultOnly=true` (только ульта: захват → кинематика → окно → 6 номеров →
`/sinclair cinematic off` → обрыв). Снимки ждут **синхронизированный тик хода** (`shotAt`, `shotAct`), но при
llvmpipe кадр снимается на ~5 тиков позже ворот. Клавиши нажимаются настоящие (`KeyMapping`), сцена — плоский
мир, доброволец — кадавр без ИИ (1000 HP), поэтому настоящая карта — запасной номер; для остальных номеров
форма задаётся в состоянии сервера во время кинематики (как и в прошлом прогоне).

```
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 ALSOFT_DRIVERS=wave ALSOFT_CONF=alsoft.conf \
JAVA_TOOL_OPTIONS="-Dviltrumitecore.sinclair.playtest=true -Dviltrumitecore.sinclair.playtest.ultOnly=true -Xmx1700m" \
./gradlew :viltrumitecore:runClient --no-daemon
python3 docs/reports/sinclair-playtest/2026-11-02/make_sheets.py viltrumitecore/run/screenshots
```

Первый запуск: `:viltrumitecore:downloadAssets` (повторить при тайм-аутах), `run/options.txt` с
`onboardAccessibility:false`, и каждый прогон — с удалённым `run/saves/sinclair_playtest` (иначе Forge
показывает экран «экспериментальные настройки»).

## Проверено логом

- Заморозка: игрок держал W 1 с посреди кинематики — сдвиг **0.000** блока.
- `/sinclair cinematic off`: после захвата ход `null` (кинематики нет), сразу окно.
- Обрыв: доброволец удалён на тике 20 → через 8 тиков `move null`, `ult WINDOW`, `controlled false`.
- `/kill` добровольца посреди сцены её **не** обрывает: урон по замороженному копится до снятия заморозки
  (общее правило контроля, как у остановки времени) — описано в спецификации.
- Звуки ([sounds_played.txt](sounds_played.txt)): сыграли все 14 новых (`viltrumitecore_sinclair:*`) и 15 старых
  звуков номеров/ульты. `copy_sting`/`copy_unfold` ×7 (7 кинематик), `copy_fold`/`copy_return` ×6 (седьмая
  оборвана до сгиба — верно). Ванильных звуков у Синклера нет; `thor.*` — от систем Тора (один удар грома
  на ~75 с записи, опознан корреляцией с файлами Тора; причину не разбирал), не от Синклера.
- WAV 129.5 с: пик вне грома Тора 1.13 (7 сэмплов > 0 dBFS при наложении нескольких звуков вплотную к слушателю);
  `copy_sting` после этого сделан тише (0.8). Сам звук **никто не слушал** — проверены только уровни.

## Найдено и исправлено в клиенте

1. Ореол карты рисовался сплошным золотым прямоугольником: `GuiGraphics.fill` выключал смешивание → `quads()` включает его сам.
2. В постановочной камере (кинематика и камеры номеров) были видны огромные руки от первого лица → `StageCamera.staged()` отменяет `RenderHandEvent`.
3. Панель реплик `HeroSubtitles` лежала под картой → прячется, пока карта на экране.
4. Сценарий: без экрана выбора героя клавиши не доходили (экран выбора открывается сам) → шаг закрытия.

## Не проверено

- Вид **добровольца-игрока** (зеркальный кадр, «Ваш номер скопирован») и синхронность двух клиентов — нужен
  второй клиент, на машине 4 ГБ / 2 ядра его не поднять. Проверены код и тесты (`CopyCinematicTest`, `CopyCardTest`).
- Выделенный сервер и задержка сети.
- Плавность: 8–19 FPS, движение камеры оценено по кадрам.
- Масштаб GUI кроме 2 и окна кроме 854×480 — только тест `StageCameraTest.cardHeight`.
