## Раскладка по умолчанию

MMB переключает Restrained → Knight → Holy Sword; переназначение сохраняется.

| Действие | До | После |
|---|---|---|
| Основной удар | ЛКМ: LightPunch / FistCombo | ЛКМ: прежняя безоружная боёвка; обнажённый Рейд — чередующиеся взмахи; приседание+ЛКМ — тяжёлый |
| Захват/бросок | Knight Z, затем ПКМ | Restrained/Knight: ПКМ по допустимой цели с пустыми руками; повторный ПКМ — бросок |
| Нога/топот | Knight Y / B | Knight Y / приседание+Y |
| Перемещение | Restrained Y; Knight V | Z во всех режимах; Knight с подходящей целью — за спину, иначе шаг-рывок |
| Ловля/отражение | Restrained Z / Knight N | Автоматическая реакция; активные слоты убраны |
| Рейд | Holy R | Holy R |
| Chop | Holy Y | Holy Y, прежняя способность сохранена |
| Rain of Cuts | Holy V | Holy V |
| World Cuts | Holy B / Z | Holy B / приседание+B |
| World Erasure | Holy N | Holy N, отдельная намеренная активация |

Контекст выбрал сервер. Если цель рывка есть, но безопасной точки за спиной нет, другой рывок не подставляется неожиданно. Захват требует допустимую цель по лучу; блок между игроком и целью и предметы в руках сохраняют vanilla use. Не выполнена полная игровая матрица контейнеров/интерактивных блоков/переназначений.

## Изменения

1. Сохранены GrabThrow, SkyKick, Stomp, StepDash, DashBehind, старые ID/порядковые номера. Обновлены loadout, HUD, описания во всех 11 существующих локалях (новые строки имеют английский fallback), input/regression-тесты. Мировые разрезы и World Erasure не удалены.
2. Независимый DefenseReaction: тип и направление в snapshot, commitment между угрозами, удержание BEAM без перезапуска action clock, плавный клиентский вес/восстановление. Действия и двухручный хват имеют приоритет. Использованы существующие клипы Parry/Catch/Reflect, а не новый движок.
3. Стрела сохраняется как та же tracked entity, удерживается 10 тиков и отпускается вниз. Подбор временно запрещён и исходная политика восстанавливается. В ходе игры обнаружена преждевременная инвентаризация при noPhysics; исправление требует повторной игровой проверки. Трезубец не превращается в стрелу. Во время активного действия или обнажённого меча применяется отклонение вместо захвата.
4. Репульсоры и ракеты теперь проходят существующий HeroProjectiles seam до собственного onHit; возврат меняет owner и Homing target. Для EyeLasers и MicroLaser добавлен отдельный hitscan hook с настоящим поглощением, без фиктивного отражения. Остальные герои не получают иной базовый урон.
5. Обнажённый Рейд использует два существующих защищённых chop-клипа, а не кулак. Быстрый удар — 14 тиков, тяжёлый — 20; нет обязательной длинной комбинации и разрушения ландшафта. Сервер проверяет пересечение клинка/нескольких целей, препятствия и однократное поражение UUID. Кэш траектории создан из итоговых equipment transforms, включая grip/roll/scale/crouch; dedicated server не загружает client classes. Это не новые уникальные клипы для каждого типа удара.
6. WORLD_CUT_BLAST больше не привязан к началу разрушения (80-й тик): оба типа играют основной акцент по DONE после окончания серверной очереди. WORK rumble существенно тише. Единый локальный 12-тиковый gate объединяет одновременные основные акценты. Громкость 5 в vanilla в основном увеличивает радиус; усиление PCM и мастеринг не выполнялись. Tail-звуки отдельных сцен могут накладываться.
7. Диагональная рана заменена узкой неровной щелью с тёмной утопленной сердцевиной, боковыми стенками и тонкими бело-золотыми краями/частицами. Ограниченное число сегментов, существующий renderer. После DONE закрытие за 70, а не 90 тиков.
8. Вместо полного AABB — проекция вдоль доминирующей горизонтальной нормали, конечное число кандидатов на колонку, O(1) память. Каждый кандидат, включая отказ, расходует прежний общий бюджет; quantum 250 и общий бюджет 2000 не увеличены. Тест сравнивает точный исходный voxel mask на 12 направлениях и дробном origin.

- Resource checker: **0 новых проблем, 6 известных legacy-проблем**.
- Настоящий dedicated server достиг Done; настоящий клиент Java17/Forge подключился по FML handshake. Выбран Рейнхард, переключены режимы, выполнены draw, ЛКМ, B, приседание+B, захват и бросок ПКМ. Голем с включённым AI после броска: Z 1.90 → 51.49, Y -59.7 → -49.16. NoAI-моб получает урон, но не служит достоверным тестом обычного полёта.
- Проверена запись FP/TP/разрезов через Xvfb/Mesa software renderer. Это smoke, не визуальная приёмка на игровом GPU. Слышимость/клиппинг не проверены: OpenAL не нашёл устройство. Для освобождения памяти parent Gradle runClient остановлен после запуска child JVM; это не clean exit runClient. Сервер завершён командой stop.
- В ограниченной среде первая попытка сервера с heap512m получила OOM; повтор с heap1024m загрузился и обслуживал клиент. При входе один Can't keep up на 40 тиков. Из этого нельзя делать вывод об отсутствии TPS-регрессий.

## Сравнение World Cut: модель очереди, НЕ live TPS

Сценарии: origin (0.5,100,0.5), seed61, build-height [-64,320), yaw 0/45/90/135, pitch -35/0/35. Старый AABB и новый iterator; число посещённых кандидатов, включая air/rejects. Предполагается один job без конкуренции, 2000 посещений/тик. DONE = max(110, 80+ceil(visits/2000)); 20TPS использовано только для перевода тиков в секунды. Фактический порядок scheduler может отличаться на тик; стоимость block updates/chunks/мобов не моделируется.

| yaw/pitch | Старый diagonal visits | Новый diagonal visits | Ground visits | Carve diagonal старый → новый | DONE diagonal / Ground (тики от старта) |
|---|---:|---:|---:|---:|---:|
| 0 / 0 | 399960 | 97768 | 149957 | 200 → 49 | 129 / 155 |
| 45 / 0 | 1332144 | 99528 | 155983 | 667 → 50 | 130 / 158 |
| 0 / ±35 | 1306440 | 319352 | 149957 | 654 → 160 | 240 / 155 |
| 45 / ±35 | 3295208 | 222984 | 155983 | 1648 → 112 | 192 / 158 |

Подготовка до BLAST: 80 тиков (4.0с) у обоих; минимум damaging wave: 30 тиков. Горизонтальный diagonal DONE по модели: 6.45–6.50с, Ground: 7.75–7.90с; наклонный diagonal: 9.60–12.00с. Новый fade после DONE: одинаковые 70 тиков (3.5с), старый diagonal: 90 (4.5с). Снижение visits: **4.09–14.78×**. Оптимизация не обещает равную продолжительность при любой геометрии; при pitch ±35 остаётся до 1.55× по DONE. Два одновременных job делят общий бюджет: эти одиночные числа нельзя выдавать за concurrent benchmark.

Полная таблица: `reinhard-carve.csv` рядом с отчётом; воспроизведение — WorldCutWorkBenchmarkTest.

## Открытые пункты — до снятия draft

- Полная матрица защитных реакций против всех героев и режимов, включая Unibeam/PulseUnibeam и splash. Эти лучи не получили отдельную постановку в этом PR.
- Точное совпадение луча/ладони и стрелы/конечных костей: сейчас beam завершается на hitbox, стрелу держит приближённый server palm anchor. Это не доказанный физический контакт с фактической моделью руки.
- Реакции во время активной атаки/с обнажённым Рейдом упрощены до TP torso lean, FP arm overlay уступает действию. EVADE не является полноценным отдельным FP-уклонением. Полноценный авторский набор разных реакций не завершён.
- Новые defense final-bone/full-mesh continuity gates; полноценное FP/TP/движение/мультиугольное ревью. Exact FP blade trajectory не подтверждена bake-тестом TP.
- Повторная игровая проверка исправленного pickup lock, многочисленных одновременных попаданий и реальных owner/target отражённых ракет.
- Измерение настоящих серверных carve/DONE фаз, TPS/FPS на одинаковой заполненной сцене и двух одновременных разрезах. Сейчас только детерминированная модель и smoke.
- Прослушивание обоих DONE-акцентов, PCM peak/мастеринг и concurrent tail mixing.
- Полная проверка vanilla-интеракций, произвольных переназначений и migration loadout в игре; разные версии клиента/сервера не поддерживаются как acceptance.
